Ice Sag View · 2.7.5

Getting started

Open Katapult Pro Maps or Photos View in desktop Chrome on an authorized account. Select a calibrated, connection-associated midspan photo with traced wires and use the Ice Sag toolbar. Turn it off before editing or when finished.

Existing versus make-ready heights

With Make Ready View off, Ice Sag uses the existing measured midspan heights, including wires planned for removal. With Make Ready View on, it uses make-ready heights and excludes wires planned for removal. The preview follows either view automatically without saving changes. Hover over Ice Sag to see the active baseline.

Which wires are previewed?

Recognized individual power conductors, including primary phases, and supported communication wires can receive their own preview. Power heights use the matching physical trace at the pole endpoint or endpoints; a wire already below the calculated height does not need additional lowering. The VDS's lowest-conductor assessment is separate.

Why isn't a wire adjusting?

  • Verify that the photo is calibrated and associated with the connection. In Maps View, select the main midspan photo. In Photos View, wait for the native viewer to load the required job context.
  • Check the wire's trace type, recognized conductor specification and span length. Hover over the Ice Sag control for calculation status.
  • Unknown wire types, ambiguous phase matches, unavailable measurements, and missing lookup rows are intentionally skipped. A recognized power span below 100 ft uses the 100-ft row for preview.
  • Refresh the page if an expected preview is not visible. If the display appears incorrect, turn Ice Sag off and stop relying on that preview.

Move or reset the toolbar

Unlock the small padlock, drag the grip to a convenient location, then lock it. While unlocked, use the reset button to restore its default location. Placement is remembered locally.

Report an issue

Open a support issue. Include the extension version, Chrome version, general wire type/specification, approximate span length, whether Maps or Photos View was open, whether Make Ready View was on, expected behavior and observed behavior. Do not include customer job IDs, coordinates, account details, photos or confidential data in a public issue.

Limitations

This independent extension uses predefined span-length-based percentage formulas for communication cables and conductor-specific lookup tables for power conductors. It provides a preview, not a clearance determination or substitute for qualified engineering review.
